# Computación en la Nube

**Ingeniería en Computación · 5º año · Universidad Nacional de Rafaela**

Repositorio de las clases presenciales de la materia.

## Cómo está organizado

Cada clase presencial tiene su carpeta, y el material de cada una viene en un
archivo comprimido **con clave**:

```
clase-1-de-docker-a-la-nube/
clase-2-del-csv-al-data-lake/
clase-3/
```

**La clave de cada clase se da en el aula, el día de la clase.** No es para hacerla
difícil: es para que lleguen sin haber leído el final. Buena parte de lo que vamos a
hacer consiste en que algo se rompa delante de ustedes y descubran por qué. Si vienen
con la respuesta leída, se pierden justamente la parte que sirve.

## Antes de cada clase

Cada carpeta tiene un `README.md` **sin clave** que dice qué preparar en casa: qué
imágenes de Docker bajar, cuánto espacio necesitan, qué tiene que estar funcionando.
Léanlo con tiempo, porque las descargas son pesadas y la conexión del campus no da
abasto si las hacemos todos juntos.

## Cómo abrir el material

Cuando tengan la clave:

**Linux / macOS**

```bash
cd clase-1-de-docker-a-la-nube
unzip clase-1.zip
```

Les va a pedir la clave. También pueden pasarla directo con `unzip -P laclave clase-1.zip`.

**Windows**

El Explorador de Windows no abre archivos comprimidos con clave. Instalen
[7-Zip](https://www.7-zip.org/) (es gratis), botón derecho sobre el archivo →
*7-Zip* → *Extraer aquí*, y les pide la clave.

En paralelo van a hacer los cursos de **AWS Academy** por su cuenta, en casa (primero
